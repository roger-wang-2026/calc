# 星光算术岛

按人教版小学 1–6 年级各册单元出计算题，可在线作答、检查，也可打印为 A4 练习卷（支持导出 PDF）。纯前端，无依赖。

## 运行
- 直接用浏览器打开 `index.html` 即可。
- 或起一个静态服务：`npx serve .` 或 `python3 -m http.server`，再访问 `http://localhost:8000`。
- 部署：把整个目录放到任意静态托管（GitHub Pages、Nginx、对象存储等）。

## 目录
- `index.html`：页面结构
- `css/style.css`：样式（含明暗主题和 A4 打印样式）
- `js/generators.js`：各年级各单元的题目生成器（要改教材范围就改这里）
- `js/practice.js`：组卷、答案解析和判题（浏览器与 Node 共用）
- `js/app.js`：界面逻辑（生成、检查、打印）
- `test/test.js`：生成器自检，`node test/test.js`

## 新增一个单元
在 `js/generators.js` 里加一行：

```js
A(5, 1, '单元名称', () => { const a = R(2, 9), b = R(2, 9); return [`${a} × ${b}`, a * b]; });
```
参数依次为：年级、学期（1 上 / 2 下）、单元名、生成函数。返回 `[算式, 答案, 作答前缀]`，作答前缀可省略（方程题用 `'x ='`）。
答案含 `…`（余数）、`:`（比）或 `%` 时按文字比对，含 `/` 的分数和纯数字按数值比对。

## 说明
单元划分按人教版教材整理，不同修订版可能有出入；目前只有计算题，没有应用题。

## 组卷与判题

- 默认不重复，各单元轮流出题；某个单元无法继续提供不同题目时，剩余题量由其他单元补充。
- 不重复模式使用有限次数尝试，不保证穷举全部题目。若未能达到所选题量，页面会显示实际题数；可扩大范围或选择“允许重复”。
- “允许重复”适合题目种类较少的低年级知识点，可反复练习同一种算式。
- 数值答案接受普通小数和分数（分母不能为零）；等值分数视为正确，目前不要求最简形式。余数支持“余”“…”和连续句点，比和百分数支持全角符号。

## 验证

`npm test` 使用固定随机序列，检查40个单元共20,000道题，覆盖普通算式、方程、解比例、余数、比、百分数、折扣和利息，并检查部分进退位约束、组卷不足与补足、判题边界。测试不代表教材版本已经逐项核对，也不包含浏览器打印布局验证。

## 计算冒险

点击“计算冒险”，按当前年级和学期进入小狐狸的六关探险：萌芽营地 → 蘑菇森林 → 星光小溪 → 云端城堡 → 巨龙山谷 → 星辰之巅。每关有故事、目标和专属勋章，地图显示已通关、可挑战及待解锁的关卡。

- 每关5～15题，按现有知识点顺序逐步扩大出题范围，同时提高题量；不是自适应难度或教材难度的严格分级。
- 冒险模式采用一题一屏：输入答案后提交，答对即自动进入下一题，也可手动点击下一题；答错必须留在原题订正，不提供跳过。所有题目答对后结算星星与勋章，没有时间限制。
- 所有题目订正正确后获得勋章；星数按首次非空作答计算：100%三星，80%以上两星，其余一星。保留历史最高星数，旧奖励不回收，重玩不扣奖励。
- 通关解锁下一关，六关全部完成可集齐六枚勋章。参考答案在冒险模式下隐藏。
- 进度使用 localStorage 保存在当前浏览器，按年级、学期独立保存；清除浏览器数据会丢失进度。存储不可用时仍可在本次页面打开期间游玩。
- `npm test` 还会验证12条路线的72个关卡配置，以及解锁、重试、收藏、存档恢复和存储不可用的行为。

## 冒险成果证书

通关任意一关后，在冒险地图的勋章收藏下点击“领取成果证书”，填写姓名或昵称即可预览并下载。姓名仅在页面本地用于制作证书，不上传，也不额外保存。

证书包含当前年级学期、已通关关数、历史最高星数、已获勋章及制作日期；未获得的勋章显示为“待点亮”。部分通关获得“闪光小探险家”称号，六关全部通关获得“星辰小勇者”，18星获得“满星传奇探险家”。可重复领取，继续通关后预览会同步更新。

- PNG：2400×1680高清图片，方便保存、分享和打印。
- SVG：可缩放的矢量图，字体随查看设备而定。
- 小狐狸、城堡和六枚徽章均为本地自绘矢量图，无需联网图片或第三方导出服务。
- `js/certificate.js` 负责证书数据和图像，相关测试覆盖称号、成果统计、姓名排版边界、内容转义和下载处理。样图已通过本地图像渲染检查；浏览器实际下载尚未进行人工实测。

## 自动构建与发布

仓库：<https://github.com/roger-wang-2026/calc>。生产域名：<https://calc.yiqiqq.com>。

- `npm run build` 将站点文件复制到 `dist/`，不包含测试、本地文件或 Git 元数据。
- 推送到 `main` 后，GitHub Actions 先运行全部测试，再构建并发布到 GitHub Pages；PR 只做测试和构建。
- 工作流：`.github/workflows/pages.yml`。仓库 Settings → Pages 的 Source 应为 GitHub Actions，自定义域名应为 `calc.yiqiqq.com`。
- Cloudflare DNS 需要添加：类型 `CNAME`，名称 `calc`，目标 `roger-wang-2026.github.io`，初始使用“仅 DNS”（灰云）。GitHub 域名检查和证书签发成功后，在 Pages 设置开启 Enforce HTTPS。
- `CNAME` 文件随发布包一并保留；使用 Actions 发布时仍需在 Pages 设置中配置自定义域名。

## 手机打印与下载

“打印 / 下载 PDF”会打开导出面板。手机可直接下载 A4 PDF，无需系统打印支持；若没有自动保存，可点击“打开 PDF 预览 / 保存”，通过文件预览的分享菜单保存或打印。微信等内置浏览器可能限制下载，此时请选择“在浏览器打开”。

PDF 在本地生成，使用当前题目、列数和留白自动分页，练习卷始终保留空白作答区。自由练习勾选“附答案页”后会单独追加参考答案；冒险模式不附答案。PDF 将分数显示为括号包围的 a/b，页面使用图像嵌入以保证中文显示，不支持文本选择。

### 单题闯关交互

进入关卡后只展示当前题目、关卡进度、小狐狸鼓励和答案输入框，隐藏地图与试卷设置。支持回车提交；正确反馈停留1.2秒后自动前进，错误提示不会自动翻页。小数题提供数字键盘，分数、余数、比和百分数题显示输入格式提示。返回地图、切换模式或年级会结束本次未完成挑战，并取消翻页定时器；已获得的勋章不变。自由练习仍为整张试卷，支持检查和下载 PDF。

## 错题再探险与首次正确率

- 首次非空作答记录一次，空白提交不计入；后续订正不会把首次错误改成首次正确。每题订正正确才能进入下一题，完成后同时显示首次正确率与“订正后全部答对”。
- 闯关中首次答错的原题自动加入本机错题库，保留所属知识点、年级与学期。同一题去重，已经掌握的题再次出错会重新列为待复练；退出未完成的关卡也不会丢掉已记录的错题。
- 地图中的“错题再探险”每次选择最多5道待复练错题，优先选择较久未复练的记录。每道安排原题与同知识点的不同变式；无法生成不同变式时只复习原题，不把重复题冒充变式。
- 连续两轮复练中，原题及变式都首次答对，标记为“已掌握”；中间答错需要重新累计。复练可以随时开始，也可第二天再回来巩固。
- 复练不会直接增加关卡星数。回到地图重新挑战，争取三星；历史最高星数与勋章不会减少。早期版本的既有星数保留。
- 错题记录在 `pep-calc-mistakes-v1`，与既有闯关进度分开存储；存储不可用时界面提示，仍可在当前页面期间练习。
